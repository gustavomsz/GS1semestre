# Uso de IA no projeto - Prioriza (Web Development)

## Ferramenta utilizada

| Ferramenta | Finalidade |
|---|---|
| Claude (Anthropic) | Revisar o site comparando com os requisitos e criar imagens em SVG |

**Período:** novembro de 2026

---

## Prompts utilizados

### 1. Revisão do projeto
- "Veja se atende a todos os requisitos" (com o link do repositório)

**O que a IA fez:** comparou o site com os requisitos de Front-end e Web Development e listou o que faltava: as 5 seções, o menu entre as seções, as variáveis CSS, o `alt` nas imagens, a pasta de imagens, o limite de palavras por parágrafo.


### 2. Criar imagens
- "Preciso de 3 imagens para o meu slideshow"

**O que a IA fez:** Gerou 3 imagens.


## Análise crítica

**Benefícios**
- A IA comparou o site com cada requisito e encontrou falhas que não tínhamos percebido, como imagens sem `alt` e parágrafos com mais de 20 palavras.
- Ajudou a testar o site em vários tamanhos de tela.
- Explicou comandos de Git que ainda não dominávamos.

**Limitações**
- Algumas respostas precisaram de correção: a primeira versão da responsividade deixava uma página maior que a tela do celular.

**Dificuldades**
- Aplicar as correções sem apagar o que já existia exigiu cuidado.
